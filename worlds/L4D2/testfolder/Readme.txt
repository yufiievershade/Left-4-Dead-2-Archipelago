Instructions for installing current build of left4dead2

Run Left 4 Dead 2 on -insecure mode

You need the latest build of Sourcemod and Metamod for Left 4 Dead 2

The L4D2_AP_Mod Folder goes in your Left4dead2/Addons Folder

Archipelago Folder, json file, and txt file go in the Sourcemod/Data Folder

All smx files go in your Sourcemod/Plugins Folder

All sp files go in your Sourcemod/Scripting Folder

The exe file is your client for testing
