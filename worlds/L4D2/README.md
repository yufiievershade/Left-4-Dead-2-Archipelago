# Left 4 Dead 2 Archipelago World

An Archipelago world implementation for Left 4 Dead 2, enabling multiworld randomization support.

## About This World

This world randomizes items and locations across Left 4 Dead 2's campaigns, allowing players to receive items from other Archipelago players while progressing through the game's various safe rooms and finales.
